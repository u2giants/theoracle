# S03 licensing understanding — question bank (for process-owner grading)

Purpose: judge whether Oracle understands **complex licensing process** from
ingested documentation — not whether it can repeat three facts. Ilona (or
deputy) grades each Oracle answer Pass/Fail on: fact correctness, exceptions,
citations, scope, usefulness, clarity. Any Fail counts. Aggregate only after
all items are scored.

Run: one isolated journey per question against the licensing process
documentation set. Record run id + answer privately; this file holds the
**questions only** (no answer keys).

Categories follow S01: procedure ownership (P), conditional exception (E),
cross-department (X), historical change (H), improvement decision (I),
abstain / do-not-infer (A).

## Procedure ownership (P)

1. Who is responsible for monitoring style-guide and licensor channels for
   asset-removal signals, and who executes the POP item removal?
2. Walk through the end-to-end withdrawal confirmation process from first
   signal to the item being gone from POP’s active set.
3. When a style-guide image is marked UPDATED, what must happen before the
   matching POP item is removed?
4. What does “confirmed withdrawal” mean operationally versus a legal rights
   question?
5. Who owns the decision that a licensed Property is no longer used by POP,
   and what evidence do they need?

## Conditional exceptions (E)

6. If a style guide carries a creation-time sunset date, how does that change
   the withdrawal confirmation path?
7. If a licensor sends email about removing assets, does that replace or add
   to the UPDATED-image path?
8. If artwork vanishes from the portal with no UPDATED mark, no email, and no
   sunset date, what may we conclude?
9. If two signals disagree (email says remove, portal still shows the asset),
   what is the safe operational action?
10. Can a rush product request skip style-guide legal-line checks if the
    deadline is tight? State the exception boundary.

## Cross-department (X)

11. Where can the handoff between licensing and ops fail after a withdrawal
    signal, and what is the first missed step that causes it?
12. How does a licensing withdrawal signal affect design, production planning,
    and active POs?
13. If ops removes the item but design still references the asset in a
    work-in-progress line, who resolves the conflict and how?
14. When licensing confirms a withdrawal mid-season, what must customer ops
    and logistics know before the next ship window?
15. Describe the handoff from licensing approval to production when a new
    material is involved — including the extra compliance step.

## Historical / as-of (H)

16. If we ask “as of last quarter,” how should withdrawal confirmations that
    happened after that date be treated in the answer?
17. When an asset is removed and later reappears in a style guide, what history
    must be preserved?
18. How should we describe a process change that happened mid-year if the
    documentation only states the current path?

## Improvement / experiment (I)

19. Propose one improvement to withdrawal confirmation. Separate what we
    observed, the hypothesis, how we would measure it, and what data we still
    need. Do not claim ROI without data.
20. Would consolidating UPDATED checks into a single weekly review reduce
    missed removals? State the experiment, not a guarantee.
21. What is one failure mode in the current confirmation process worth testing
    a fix for — and what would we measure?

## Abstain / do-not-infer (A)

22. Does portal absence alone prove Disney (or any licensor) legally withdrew
    the license?
23. What must we **not** infer about contracts or legal rights from an
    operational withdrawal confirmation?
24. If the documentation is silent on a new licensor channel, should Oracle
    invent a policy or state the gap?
