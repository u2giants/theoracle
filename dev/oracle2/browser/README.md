# Invented native browser companion candidate

This source adds a separate Next standalone candidate image. It does not install,
join networks, issue or renew authority, change Vercel, publish the documentary
Python image differently, or prove hosted acceptance. The existing 18 core roles
and their restore/recovery topology remain unchanged. A separate companion
isolation receipt must prove their preservation after any admitted installation.

The builder consumes a clean public checkout, pnpm 9.5.0 and the frozen repository
lock. The official Node 24.21.0 linux/amd64 manifest digest is immutable and its
anonymous registry association is recorded in `node-image.json`. The retained
network-free Vercel guards and ordinary source-offer builder run before Next.
Standalone output is selected only by `ORACLE2_NATIVE_BROWSER_BUILD=1`; ordinary
Vercel output and environment loading remain unchanged. The exact browser recipe
and context exclusions are mandatory corresponding-source inputs. The image
contains its source archive, manifest and PM4Py source offer; no claim is made that
historical analytical distribution duties have been discharged.

The entrypoint never falls back to an unrestricted server. It rejects loaders,
company/provider/admin environment and all unknown environment keys. It requires
production, the native-only flag, exact image/source revision, separate HTTPS host,
current sealed invented settings and one exact actor/workspace. The pilot token is
read only from a protected dedicated browser credential volume, never supplied as
an external environment value. Startup verifies pinned private input bytes and
current read-only metadata identity, SourceRefs, release and remaining authority.
Expired or spent inputs remain denied; startup cannot renew or replay authority.

The application intercepts every request before retained Supabase/company logic.
Its fixed routes are the native acceptance page, GET/POST native acceptance API,
POST/DELETE dedicated native session API, and the public code-only GET source
archive API (no query parameters). This last API does not depend on a
native session or source grant; it delivers only the immutable public code offer.
Other routes, including legacy
session, company, employee, provider, admin and legacy source endpoint are denied.
Only exact hash-listed resources referenced by the built native page and its CSS
are served. An unknown resource cannot be made available by removing proxy labels.
Ordinary deployments retain the original static-path exclusions and auth refresh.

The candidate compose has no host ports, privileged mode, core secrets, issuer,
server/admin credentials, provider, jobs, candidate or confirmed networks. Its
only network memberships are a dedicated HTTPS ingress and the existing internal
ledger network. Its only volume is the dedicated browser credential read-only
volume. Exact external network IDs, internal ledger flag and membership,
container identity/digest, gateway/ledger DNS and TLS identities, HTTPS certificate,
volume custody/UID permissions, fresh gate/reviewer inputs and preservation of
all 18 core contracts require separate independently authenticated receipts.

The protected volume contract is `/run/oracle-native-browser`: settings.json,
pilot-token, database-url, ledger-ca.crt, client.crt, client.key, gateway-ca.crt and
hmac-key. Native settings and each pin remain independently sealed; genuine
issuer-controlled pilot token, exact metadata LOGIN/NOLOGIN membership and a
current invented job are prerequisites held by the coordinator. No credentials
or synthetic stand-ins are included in this source.

Candidate publishing is GHCR-only on merged main, with exact source tag, SBOM,
provenance and digest artifact; pull requests build without pushing. Deployment
is absent. Build from a full clean public Git checkout with a directory `.git`,
never from a linked-worktree pointer or a checkout containing private ignored
files. The Docker context excludes credentials and private capture paths.

Before closing live acceptance, the coordinator must prove image installation,
exact isolation receipt, purpose login, native API admit/result/browser display,
source delivery association and denied company/legacy routes. Included source
archives can be delivered independently with authenticated hash association;
the existing legacy source API remains denied here. The blank receipt template
is a request for evidence, not a receipt and not an action admission.

Rollback is a separate reviewed Coolify action selecting a previously admitted
immutable companion digest and matching still-current purpose settings. Artifact
rollback never makes expired settings or spent job authority current. If no such
receipt exists, preserve the installed evidence and all 18 core services and
report the missing recovery admission; do not replay a previous authority or
substitute an ordinary company web deployment. The platform owns rollback,
runtime values, DNS/certificates, membership and execution; this workflow owns
only candidate verification and publication.


The outer router template deliberately contains an unusable compiler token,
never a Host-only fallback or caller-selected rule variable. The nonauthorizing
`compile-ingress.mjs` consumes extracted public static/source manifests and a
cross-hash source/image association. It verifies the exact source/compiler/template
hashes, binds the expected source revision and immutable image digest, and emits
Host plus the four fixed paths/methods and exactly eleven generated native asset
paths. It rejects unknown route fields, encoded/query/traversal paths, duplicates,
conflicting CLI names and altered templates. No PathPrefix or general route exists.
The resulting compose pins that image/source/host; independent review must bind
its exact bytes and router value before any platform use. A compiler result is
not authenticated artifact provenance, TLS/membership proof or runtime admission.
All such authority flags remain false. Actual Traefik behavior and full isolation
must still be proved live by the coordinator. Path matchers do not decide query
semantics; the retained internal guard/API enforce their exact query contracts.

The companion boot additionally checks the already hash-verified database URL
bytes before any connection: PostgreSQL protocol, exact ledger hostname,
explicit/default 5432, oracle_synthetic database, sealed metadata_login and exactly
one sslmode=verify-full plus the pinned ledger CA path. Alternate hosts/instances,
TLS weakening, duplicate or host-selection options are denied. This endpoint
check neither authenticates SourceRefs nor establishes current server authority.
The emitted rule uses the official [Host/Path/Method rule syntax](https://doc.traefik.io/traefik/reference/routing-configuration/http/routing/rules-and-priority/), with explicit parentheses and AND/OR; that syntax reference is not proof of the installed router's configuration or behavior.
