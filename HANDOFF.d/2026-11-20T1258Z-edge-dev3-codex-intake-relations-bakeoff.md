## 1. What this application is

Oracle builds an evidence-backed Company Map of repeated work, responsibilities and decisions. It reads company sources and answers staff questions with supporting evidence. This work adds approved email, Teams chat and ClickUp sources. The public repository contains the Python brain, the web application and the plan. The benchmark corpus and all excerpts are in a dedicated private Coolify sandbox. [Repository guide](https://github.com/u2giants/theoracle/blob/main/AGENTS.md) · [Implementation plan](https://github.com/u2giants/theoracle/blob/main/plan_pm_message_intake.md).
