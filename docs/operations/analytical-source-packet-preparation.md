# Analytical public-source packets: inert source preparation

The committed source manifest remains unqualified:37 intact archives,
267363376bytes and280 chunks. All source descriptors, six native solver binaries,
seven original PuLP notices and unresolved historical associations remain intact.
This helper changes no manifest, rights, installation, runtime, route or product
flag. It downloads nothing, extracts nothing and contacts no supplier/provider.
The existing analytical packet validator remains the source/notice policy owner.

`SourcePacketStore` binds the entire raw manifest SHA, exact40-character product
revision and immutable image SHA to fixed artifact IDs. Request JSON cannot pass
an authority or grant. No URL, filename, downloader, proxy or alternate path is
accepted by the chunk request. The configured directory roots and authority
object are trusted server integration dependencies; they are not request fields.

The current independent product-delivery resolver defaults to absent and denies
before any archive/cache byte open. No resolver implementation, actual registry,
authentication route or registration mechanism is added here. A future separately
reviewed integration must resolve authentic independent product, notice, delivery
and current-principal permission receipts against that exact product binding.
Typed receipt fields and hashes do not themselves prove approval. Supplying a
boolean, hash, arbitrary callback, changed rights or an expired/moved permission
cannot enable this helper. Invented test authorities are local fixtures only.
This module never issues product approval or a delivery decision.

After a trusted current permission exists, the helper opens only the manifest's
fixed local filename through nofollow directory descriptors. Each intact archive
must fit64MiB. It verifies its actual complete length/hash in one bounded pass,
rechecking permission while reading, and creates a protected0400 content-addressed
cache under an owned0700 directory without overwriting existing files. Symlinks,
foreign custody and changed file identities refuse. Archive bytes and all embedded
binaries/notices remain intact; there is no pruning or rewritten archive.

Every response rechecks current product/principal permission before cache reads
and before returning, serves the exact indexed range of at most1MiB, and binds
chunk/archive/product hashes. A client can check complete ordered reconstruction
against the whole intact archive hash and size; that is an integrity proof,
not an authority receipt. The trusted OS owner/cache custody remains a boundary;
this prototype does not defend against an OS owner bypassing the helper.

Tests use invented local archive bytes only. They cover default denial before
opens, whole-manifest/revision/image mismatches, notices/rights/native-binary
preservation, actual size/hash mismatch, chunk limits, cross-artifact/reordered
reconstruction, source/cache links/collisions, current revocation/expiry and exact
reconstruction after a single original read. Root integrates their inventory and
this document's router entry after source review. Actual supplier source payloads,
historical CBC ARM/Win32/AMPL builder inputs, full product/runtime/notice review,
installation and authenticated delivery remain unqualified external/root gates.
